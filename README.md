# 하루관리 (Daily App)

건강·생활습관 기록, 할 일, 습관 트래커를 한 곳에서 관리하는 모바일 앱입니다. (React Native + Expo SDK 58)
모든 데이터는 **기기 안에만** 저장됩니다(AsyncStorage). 서버나 계정이 필요 없습니다.

## 기능
하단 탭: **달력 · 운동 · 식단 · 체중 | 🏠 홈 | 목표 · 할 일 · 습관 · 리포트** (홈은 가운데 원형 버튼)

| 탭 | 내용 |
|---|---|
| 📅 달력 | 날마다 3개 링(바깥 활동=운동·걸음, 가운데 건강=수면·식사, 안쪽 루틴=할 일·습관·목표), ⭐ 링을 모두 채운 날, 목표 기간을 형광펜 띠로 표시, 날짜를 누르면 그날 상세, 목표 타임라인(기간 경과 vs 달성), 다음 달 미리보기 |
| 🏃 운동 | 운동(종류·분), 걸음 수(iOS 만보기 불러오기), 주간/월간 그래프 + 하루 평균·합계·목표 달성일 |
| 🍚 식단 | 식사(아침/점심/저녁/간식) + 사진(촬영·앨범), 🤖 사진으로 칼로리·탄수화물·단백질·지방 AI 추정(직접 수정 가능), 하루 탄단지 비율(권장 비율과 비교), 칼로리 주간/월간 그래프 |
| ⚖️ 체중 | 체중 + BMI, 체중 변화 그래프(평균, 최저~최고, 기간 변화, 주당 평균 감량 추세, 다이어트 목표의 계획 페이스 점선), 수면 그래프, 키 |
| 🏠 홈 | 날씨, 하루 리포트(어제/오늘 점수 링 + 항목별 달성률 링 + 그날 한 일 요약 + 이번 주 등급), 목표 진행(주당 페이스 한 줄 요약), 빠른 기록(체중·BMI), 할 일·습관, ⚙️ 설정 |
| 🎯 목표 | 장·단기 목표 달성도(%) — 체중 / 매일 실천(연속·누적, 최근 7일 놓친 날 체크 가능) / 누적 수치. 시작일을 미래로 정할 수 있음(예: 11월 1일부터 100일) |
| 📝 할 일 | 날짜별 할 일, 중요 표시, 밀린 일 오늘로 옮기기 |
| 🔥 습관 | 최근 7일 체크, 연속 달성일 |
| 📋 리포트 | 주간(월~일)·월간 성적표: 종합 점수와 S~F 등급, 날짜별 등급 막대, 과목별 성적, 목표 관리 실적(계획 대비), 생활 기록 요약, 종합 의견 |

그래프는 **주간(월~일) / 월간(달력 월) / 3개월(주 평균)** 으로 볼 수 있고, ‹ › 로 지난 기간을 넘겨봅니다.
각 탭 카드 오른쪽 위 "목표 N ✎" 또는 홈의 ⚙️ 설정에서 하루 목표를 바꿀 수 있습니다.

### 데이터 백업
모든 기록은 휴대폰 안(AsyncStorage)에만 저장됩니다. ⚙️ 설정 → **백업 파일 내보내기**로 `.json` 파일을 만들어 드라이브·메일 등에 보관하고, **백업 파일에서 복원**으로 되살릴 수 있습니다.

## 다른 앱 기록 가져오기 (⚙️ 설정)
- **헬스 커넥트 (안드로이드)**: 삼성 헬스·앳플리 등이 헬스 커넥트로 보낸 걸음 수·체중·수면·운동을 기간(1달~5년)을 정해 가져오고, "앱을 열 때 자동으로 가져오기"를 켜면 최근 7일을 계속 맞춰 줍니다 (걸음 수는 기기 값으로 갱신, 나머지는 빈 날만).
- **파일**: 삼성 헬스 '개인 데이터 다운로드' CSV(체중, 걸음, 수면, 운동), 애플 건강 export.xml, 날짜와 체중/걸음 열이 있는 CSV. 여러 파일을 한 번에 고를 수 있고, 가져오기 전에 찾은 기록과 기간을 보여 줍니다.
- 이미 기록한 날은 "그대로 두기 / 가져온 값으로 바꾸기" 중에 고릅니다. 체중은 그날 첫 측정값, 수면은 깬 날짜 기준입니다.

## 디자인 · 접근성
- 색: 글자는 배경과 명암 대비 4.5:1 이상(WCAG AA). 그래프용 밝은 색을 글자나 버튼 바탕으로 쓸 때는 `ink()` / `solid()`(`src/theme.ts`)가 같은 색조로 밝기만 낮춰 대비를 맞춥니다.
- 화면 읽기(TalkBack · VoiceOver): 버튼·탭·체크박스·선택지에 역할과 이름, 선택/체크 상태가 있고, 이모지는 읽지 않습니다. 점수 링·그래프·달력 날짜는 숫자를 문장으로 읽어 줍니다. AI 분석 진행/오류는 바로 알려 줍니다.
- 누르는 영역은 44~48dp 이상, 입력칸 글자 16px(아이폰 자동 확대 방지), 웹앱 핀치 확대 허용.
- 웹 빌드는 axe-core 검사에서 모든 탭과 설정 창에 위반 0건.

## 🤖 식사 사진 AI 분석 (Claude API)
식단 탭에서 **📷 사진 찍기 / 🖼️ 앨범에서**로 사진을 넣으면 Claude가 음식과 양을 보고 열량·탄수화물·단백질·지방을 추정해 칸을 채웁니다. 숫자는 저장 전에 고칠 수 있고, 사진 없이 메뉴만 적고 **🤖 AI로 추정**을 눌러도 됩니다.
- **본인 Claude API 키가 필요합니다**: [Claude 콘솔](https://platform.claude.com)에 가입 → Settings › Billing에서 크레딧 충전 → Settings › API Keys에서 키 생성 → 앱의 ⚙️ 설정 › 🤖 사진 칼로리 분석에 붙여넣기 (키는 무료 모델 정보 조회로 확인 후 저장).
- **분석 방식**: 정확하게(Claude Opus 5.5, 사진 1장 약 30~70원) / 저렴하게(Claude Haiku 5.5, 약 1~3원). 사진은 긴 변 1280px JPEG로 줄여서 보냅니다.
- Opus 5.5 요청에는 서버 측 거절 대비(`fallbacks: "default"`, 베타 `server-side-fallback-2026-07-01`)가 켜져 있어, 안전 정책으로 거절되면 Anthropic이 권장하는 모델로 같은 요청을 다시 처리합니다. Haiku 5.5는 이 기능이 없습니다.
- 응답은 구조화 출력(JSON 스키마)으로 받고(`src/ai/mealAnalysis.ts`), 음식별 값을 앱에서 합산합니다.
- 개인정보: 분석할 때만 사진이 Anthropic 서버로 전송됩니다. API 키는 안드로이드 키스토어(expo-secure-store) / 웹앱은 그 브라우저에만 저장되고 백업 파일에는 들어가지 않습니다.
- 사진 저장: 안드로이드는 앱 전용 폴더(`meal-photos/`), 아이폰 웹앱은 브라우저 IndexedDB. **사진은 백업 파일에 포함되지 않습니다.** 식사를 지우면 사진도 지워집니다.

## 성적표 (리포트 탭)
- 종합 점수 = 기간 안의 하루 점수 평균. 기록이 없는 날은 0점(결석), 앱을 쓰기 전 날짜는 제외, 오늘은 하루가 끝난 뒤 반영
- 등급: S 90↑ · A 80↑ · B 70↑ · C 60↑ · D 50↑ · F 50 미만
- 목표 관리 등급: 이 기간 계획한 양 대비 실적 (체중은 계획 체중 변화, 매일 실천은 체크한 날, 누적 수치는 계획량)

## 하루 점수 (100점 만점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 👟 걸음 | 15 | 목표 걸음 수 대비 |
| 🏃 운동 | 20 | 목표 운동 시간 대비 |
| 😴 수면 | 15 | 목표 수면 시간 대비 |
| 🍚 식사 | 15 | 아침·점심·저녁 기록 수 / 3 |
| 📝 할 일 | 10 | 그날 할 일 완료 비율 (할 일이 없으면 제외) |
| 🔥 습관 | 15 | 습관 완료 비율 (그날 이후에 만든 습관은 제외) |
| 🎯 목표 | 15 | 진행 중인 '매일 실천' 목표 체크 비율 (없으면 제외) |

제외된 항목이 있으면 나머지 항목으로 100점 환산합니다. 계산 로직은 `src/score.ts`.

## 날씨
[Open-Meteo](https://open-meteo.com) 무료 API(키 불필요)를 사용합니다. 위치 권한을 거부하면 서울 날씨를 보여줍니다.

## Android 설치 파일(APK) 만들기
```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
# 결과: android/app/build/outputs/apk/release/app-release.apk
```
JDK 17, Android SDK(platform 37, build-tools 37.0.0, NDK 27.1, CMake 3.30.5)가 필요합니다.

## 아이폰 (웹앱)
아이폰은 설치 파일을 직접 깔 수 없어서 웹앱으로 씁니다. 사파리에서 웹앱 주소를 열고 **공유 → 홈 화면에 추가**하면 앱처럼 전체 화면으로 실행되고, 인터넷이 없어도 열립니다.
- 기록은 그 아이폰(홈 화면 앱) 안에만 저장됩니다. 사파리 탭과 홈 화면 앱은 저장 공간이 따로라서 항상 홈 화면 아이콘으로 여세요.
- 만보기 자동 불러오기만 안 되고 나머지 기능은 같습니다. 백업은 ⚙️ 설정에서 파일로 내보내고 복원합니다.
- 배포: `scripts/deploy-web.sh <저장소 이름>` → GitHub Pages(gh-pages 브랜치). 새 버전을 올릴 때는 `public/sw.js`의 `CACHE` 이름도 올려 주세요.

## 실행 방법
```bash
npm install
npx expo start
```
휴대폰에 **Expo Go** 앱을 설치한 뒤 터미널에 나오는 QR 코드를 찍으면 바로 실행됩니다.
브라우저로 미리 보려면 `npx expo start --web`.
