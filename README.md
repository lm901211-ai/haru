# 하루관리 (Daily App)

건강·생활습관 기록, 할 일, 습관 트래커를 한 곳에서 관리하는 모바일 앱입니다. (React Native + Expo SDK 58)
모든 데이터는 **기기 안에만** 저장됩니다(AsyncStorage). 서버나 계정이 필요 없습니다.

## 기능
| 탭 | 내용 |
|---|---|
| 🏠 오늘 | 오늘의 날씨(현재 위치), 하루 점수 리포트(어제 대비·최근 7일), 물·걸음·운동·수면 달성률, 목표 진행 요약, 오늘 체중 입력 + BMI, 할 일·습관 체크 |
| 🎯 목표 | 장·단기 목표(30일 이하 단기, 초과 장기)와 달성도(%) 표시. **체중**(목표 체중 또는 주당 감량/증량 목표, 최근 1주 페이스 확인), **매일 실천**(연속/누적 일수, 예: 영어 공부 100일 연속), **누적 수치**(예: 책 12권, 영단어 1000개). 기간상 지금쯤 와 있어야 할 지점을 막대에 표시해 순항/뒤처짐을 알려줌 |
| ❤️ 건강 | 날짜별 물(잔), 걸음 수(iOS는 휴대폰 만보기에서 불러오기 가능), 운동(종류·분), 식사(아침/점심/저녁/간식, kcal), 수면, 체중, 내 정보(키), 하루 목표 설정 |
| 📝 할 일 | 날짜별 할 일, 중요 표시(★), 지난 미완료 일을 오늘로 옮기기 |
| 🔥 습관 | 습관 추가(이모지), 최근 7일 체크, 연속 달성일(🔥) 표시, 길게 눌러 삭제 |

## 하루 점수 (100점 만점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 💧 물 | 15 | 목표 잔 수 대비 |
| 👟 걸음 | 15 | 목표 걸음 수 대비 |
| 🏃 운동 | 20 | 목표 운동 시간 대비 |
| 😴 수면 | 15 | 목표 수면 시간 대비 |
| 🍚 식사 | 10 | 아침·점심·저녁 기록 수 / 3 |
| 📝 할 일 | 10 | 그날 할 일 완료 비율 (할 일이 없으면 제외) |
| 🔥 습관 | 15 | 습관 완료 비율 (습관이 없으면 제외) |

제외된 항목이 있으면 나머지 항목으로 100점 환산합니다. 계산 로직은 `src/score.ts`.

## 날씨
[Open-Meteo](https://open-meteo.com) 무료 API(키 불필요)를 사용합니다. 위치 권한을 거부하면 서울 날씨를 보여줍니다.

## 실행 방법
```bash
npm install
npx expo start
```
휴대폰에 **Expo Go** 앱을 설치한 뒤 터미널에 나오는 QR 코드를 찍으면 바로 실행됩니다.
브라우저로 미리 보려면 `npx expo start --web`.

## 폴더 구조
```
App.tsx                 하단 탭 + 화면 전환
src/store.tsx           데이터 저장/불러오기 (AsyncStorage)
src/types.ts            데이터 타입
src/date.ts             날짜 유틸, 연속 달성일 계산
src/score.ts            하루 점수, BMI 계산
src/challenges.ts       장·단기 목표 달성도 계산
src/weather.ts          위치 + 날씨 불러오기
src/components/ui.tsx   공용 UI 컴포넌트
src/screens/            오늘 / 건강 / 할 일 / 습관 화면
```
