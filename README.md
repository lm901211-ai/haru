# 하루관리 (Daily App)

건강·생활습관 기록, 할 일, 습관 트래커를 한 곳에서 관리하는 모바일 앱입니다. (React Native + Expo SDK 58)
모든 데이터는 **기기 안에만** 저장됩니다(AsyncStorage). 서버나 계정이 필요 없습니다.

## 기능
하단 탭: **운동 · 식단 · 체중 | 🏠 홈 | 목표 · 할 일 · 습관** (홈은 가운데 원형 버튼)

| 탭 | 내용 |
|---|---|
| 🏃 운동 | 운동(종류·분), 걸음 수(iOS 만보기 불러오기), 주간/월간 그래프 + 하루 평균·합계·목표 달성일 |
| 🍚 식단 | 식사(아침/점심/저녁/간식, kcal), 물, 칼로리·물 섭취 주간/월간 그래프 |
| ⚖️ 체중 | 체중 + BMI, 체중 변화 그래프(평균, 최저~최고, 기간 변화, 주당 평균 감량/증가), 수면 그래프, 키 |
| 🏠 홈 | 날씨, 하루 리포트(어제/오늘 점수 링 + 항목별 달성률 링), 루틴 관리도(최근 14일, CL/UCL/LCL/LSL, Cpk), 목표 진행, 빠른 기록, 할 일·습관 |
| 🎯 목표 | 장·단기 목표 달성도(%) — 체중 / 매일 실천(연속·누적) / 누적 수치 |
| 📝 할 일 | 날짜별 할 일, 중요 표시, 밀린 일 오늘로 옮기기 |
| 🔥 습관 | 최근 7일 체크, 연속 달성일 |

각 탭 카드 오른쪽 위 "목표 N ✎"을 눌러 하루 목표를 바꿀 수 있습니다.

## 루틴 관리도
최근 14일(오늘 제외) 하루 점수로 품질관리 관리도를 그립니다.
- CL = 평균, UCL/LCL = 평균 ± 3σ, LSL = 목표 하한 70점
- Cpk = (평균 − 70) ÷ 3σ → 1.33 이상 매우 안정, 1.0 이상 안정, 그 미만은 점수가 자주 70점 아래로 떨어지는 상태

## 하루 점수 (100점 만점)
| 항목 | 배점 | 기준 |
|---|---|---|
| 💧 물 | 15 | 목표 잔 수 대비 |
| 👟 걸음 | 15 | 목표 걸음 수 대비 |
| 🏃 운동 | 20 | 목표 운동 시간 대비 |
| 😴 수면 | 15 | 목표 수면 시간 대비 |
| 🍚 식사 | 10 | 아침·점심·저녁 기록 수 / 3 |
| 📝 할 일 | 10 | 그날 할 일 완료 비율 (할 일이 없으면 제외) |
| 🔥 습관 | 15 | 습관 완료 비율 (습관이 없으면 제외) |

제외된 항목이 있으면 나머지 항목으로 100점 환산합니다. 계산 로직은 `src/score.ts`.

## 날씨
[Open-Meteo](https://open-meteo.com) 무료 API(키 불필요)를 사용합니다. 위치 권한을 거부하면 서울 날씨를 보여줍니다.

## 실행 방법
```bash
npm install
npx expo start
```
휴대폰에 **Expo Go** 앱을 설치한 뒤 터미널에 나오는 QR 코드를 찍으면 바로 실행됩니다.
브라우저로 미리 보려면 `npx expo start --web`.

## 폴더 구조
```
App.tsx                 하단 탭 + 화면 전환
src/store.tsx           데이터 저장/불러오기 (AsyncStorage)
src/types.ts            데이터 타입
src/date.ts             날짜 유틸, 연속 달성일 계산
src/score.ts            하루 점수, BMI 계산
src/challenges.ts       장·단기 목표 달성도 계산
src/weather.ts          위치 + 날씨 불러오기
src/components/ui.tsx   공용 UI 컴포넌트
src/components/charts.tsx  링 게이지, 추이 그래프, 관리도 (react-native-svg)
src/components/home.tsx 홈 화면 카드들
src/screens/            운동 / 식단 / 체중 / 홈 / 목표 / 할 일 / 습관 화면
```
