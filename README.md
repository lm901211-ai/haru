# 하루관리 (Daily App)

건강·생활습관 기록, 할 일, 습관 트래커를 한 곳에서 관리하는 모바일 앱입니다. (React Native + Expo SDK 58)
모든 데이터는 **기기 안에만** 저장됩니다(AsyncStorage). 서버나 계정이 필요 없습니다.

## 기능
| 탭 | 내용 |
|---|---|
| 🏠 오늘 | 오늘의 물·걸음·운동·수면 달성률, 오늘 할 일 체크, 습관 원탭 체크 |
| ❤️ 건강 | 날짜별 물(잔), 걸음 수(iOS는 휴대폰 만보기에서 불러오기 가능), 운동(종류·분), 식사(아침/점심/저녁/간식, kcal), 수면, 체중, 하루 목표 설정 |
| 📝 할 일 | 날짜별 할 일, 중요 표시(★), 지난 미완료 일을 오늘로 옮기기 |
| 🔥 습관 | 습관 추가(이모지), 최근 7일 체크, 연속 달성일(🔥) 표시, 길게 눌러 삭제 |

## 실행 방법
```bash
npm install
npx expo start
```
휴대폰에 **Expo Go** 앱을 설치한 뒤 터미널에 나오는 QR 코드를 찍으면 바로 실행됩니다.
브라우저로 미리 보려면 `npx expo start --web`.

## 폴더 구조
```
App.tsx                 하단 탭 + 화면 전환
src/store.tsx           데이터 저장/불러오기 (AsyncStorage)
src/types.ts            데이터 타입
src/date.ts             날짜 유틸, 연속 달성일 계산
src/components/ui.tsx   공용 UI 컴포넌트
src/screens/            오늘 / 건강 / 할 일 / 습관 화면
```
